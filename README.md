Flex Lexical Analyzer Examples
Description

A collection of Flex programs demonstrating lexical analysis by identifying keywords, identifiers, numbers, operators, and special characters.

Requirements
Ubuntu/WSL
Flex
GCC
Git
Examples
Example 1: Integers and identifiers
Example 2: Keywords and operators
Example 3: Lexical analysis of a small program
Example 4: Token counting
How to Run

For each example:

flex -o example1.c example1.l
gcc example1.c -o example1

./example1

Replace example1 with the required example number.
